# Introduction to the Steinmetz Analysis Dashboard

Welcome to the documentation for the Steinmetz Analysis Dashboard!

This application allows users to:
- Select neural recording sessions from the Steinmetz dataset.
- Choose various types of analyses to perform on the data.
- Configure parameters for these analyses.
- View and interpret the results through dynamic visualizations.

## Key Features

- **Interactive Data Selection**: Easily choose sessions.
- **Multiple Analysis Types**: PSTH, LFP, Population Dynamics, etc.
- **Configurable Parameters**: Tailor analyses to specific needs.
- **Dynamic Visualizations**: Understand results through plots.

This documentation will guide you through the available features, how to use them, and provide some insight into the underlying data and analysis methods.
